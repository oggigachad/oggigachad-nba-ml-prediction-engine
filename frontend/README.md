# NBA Prediction Frontend

This is a Vite + React frontend for the NBA Prediction Engine.

## Development

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features

- **Game Outcome Prediction**: Predict match winners using team metrics
- **Player Performance Prediction**: Forecast individual player points
- Modern UI with glassmorphism design
- Multiple ML model options (Logistic Regression, SVM, Linear Regression, SVR)
